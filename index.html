State diagram

Yellow node = current state. Double circle = halting state. Edge labels: read→write,move. The edge of the rule that runs next is highlighted.

Transition table

Each cell = write , move , next state. Rows are states, columns are the symbol under the head.

Rules (editable - write your own machine!)

One rule per line: state read write move next. Move is L, R or N (stay). _ is the blank symbol, * matches any symbol (as write it keeps the symbol). The first rule's state is the start state (or add a line start: q0). States named halt, accept, reject (or with no outgoing rules) stop the machine. Comments start with #.
